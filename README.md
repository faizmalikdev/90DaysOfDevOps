# 90-Day DevOps & Cloud Learning Plan

## Current Level

I am currently pursuing MCA and have a background in Full Stack Development. I have experience with JavaScript, React.js, Node.js, Express.js, MongoDB, SQL, Git and GitHub. I have built MERN projects and understand application development, but I want to improve my knowledge of Linux, deployment, cloud infrastructure, automation and DevOps practices.

## My Understanding of DevOps & Cloud

DevOps is a combination of development, operations, automation and collaboration that helps teams build, test, deploy and maintain applications efficiently and reliably.

Cloud Engineering is about using cloud platforms and services to build, deploy, manage and scale applications and infrastructure.

My goal is not just to learn DevOps tools. I want to understand **why and when to use them** and become comfortable troubleshooting real deployment problems.

## Why I Am Learning DevOps & Cloud

As a Full Stack Developer, I don't want my knowledge to stop at writing application code. I want to understand what happens after the code is pushed to GitHub: how applications are deployed, how servers are managed, how CI/CD works, how containers are used and how applications run on cloud platforms.

I also want to become eligible for **DevOps, Cloud and Software Development roles** and strengthen my overall engineering skills.

## My 3 Goals for the Next 90 Days

1. Build a strong foundation in **Linux, Networking, Git and DevOps fundamentals** and become comfortable working from the command line.

2. Learn and implement **Docker, CI/CD and AWS** by deploying my own application and automating its deployment process.

3. Understand **Kubernetes and basic cloud infrastructure** and deploy a containerized application on a Kubernetes environment.

## 3 Core Skills I Want to Build

### 1. Linux & Troubleshooting

Commands, file permissions, processes, services, networking, logs, SSH and basic troubleshooting.

### 2. CI/CD & Automation

Git/GitHub, GitHub Actions, Docker and automated build, test and deployment pipelines.

### 3. Cloud & Containers

AWS fundamentals, EC2, IAM, networking basics, Docker, Kubernetes and application deployment.

## Weekly Time Commitment

I will study approximately **2 hours on weekdays and 3–4 hours on weekends**, depending on my MCA classes and other responsibilities.

My priority will be:

**Learn → Practice → Build → Document → Revise**

I will spend more time doing hands-on practice than only watching tutorials.

## My Consistency Rule

I will work on DevOps every day, even if I have limited time.

On a busy day, I will complete at least **30 minutes of learning or practical work** instead of skipping the day completely.

I will maintain my progress through GitHub notes, daily tasks and small practical projects.

## 90-Day Outcome

By the end of these 90 days, I want to be able to take a web application from **source code to a working cloud deployment**, understand the basic infrastructure behind it, automate its deployment and troubleshoot common Linux, Docker, networking and deployment issues.

My target is not perfection.

**My target is consistency, practical knowledge and becoming job-ready.**
